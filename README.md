# ShamenNextGen

Examples and projects for data engineering, cloud integrations, and analytics.

## Projects

### AWS Event-Based Solution - Databricks

An event-driven integration that detects new objects in either of two S3 buckets and submits a Databricks serverless job through the Jobs API. The project includes Terraform infrastructure, the Lambda handler, and small CSV samples.

See the [project README](AWS%20Event%20Based%20Solution%20-%20Databricks/README.md) for architecture, prerequisites, configuration, deployment, and testing instructions.
